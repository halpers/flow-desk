# M7.6 账号与角色管理

本阶段实现同租户后台账号列表、新增、启停、改名、重置密码、内置/自定义角色及多角色分配。账号名全局唯一且不可改；密码只接受本次操作者输入，不回显、不进入审计或幂等明文。角色是权限并集：每个账号至少一个内置基础角色，可附加自定义增量角色；基础角色以 admin > supervisor > operator 决定既有团队/知识 ACL 范围。自定义角色只从服务端允许的增量权限目录选择，不赋予 admin 的资源范围豁免。内置角色不可修改/禁用；无角色继承或拒绝规则。

Go 拥有 roles/user_roles 及用户的权限投影。历史账号回填内置关联，新租户/旧版账号 INSERT 通过迁移触发器建立基础关联。所有管理写在租户授权排他锁下复核当前管理员和版本，账号/分配/权限投影、会话撤销、审计及幂等同事务提交；角色修改同时刷新所有关联账号。禁用、重置密码及权限变更撤销全部会话，旧 run family/capability 不因重新登录恢复。登录/刷新与变更使用同一授权锁，防止旧密码校验后创建新会话。不能移除最后一个启用的内置管理员，不允许修改自身登录凭据、启停或角色；本人改密由[M7.28](m7-self-password.md)独立提供，管理员维护入口的自身保护保持。

账号列表默认每页 20、最多 100 条，游标绑定租户；角色目录最多 53 条。响应隐藏密码/hash、会话与内部定位。新增/重置的密码请求摘要使用服务端 HMAC，不保存密码明文或无盐密码摘要；同键同内容重放不重复创建或撤销新登录。当前操作者、租户及目标身份在重放时仍验证。页面权限仅用于交互，Go 为最终授权边界。

## 权限和限制

| 权限 | 操作 |
| --- | --- |
| account:manage | 本租户账号列表、新增、改名、启停、分配角色、重置密码；可读角色目录 |
| role:manage | 本租户角色目录、新增及修改自定义角色 |
| knowledge:manage | 管理基础角色 ACL 和团队范围内的知识文件 |
| team:manage | 团队和成员管理，既有资源访问规则继续有效 |
| ticket:manage / audit:read / run:observe | 工单管理、审计及任务观测，仍检查资源范围 |

account:manage 和 role:manage 是身份管理特权，可授予高权限角色，只应授予可信管理人员。内置基础角色不可改名、改权限或停用；多个基础角色取最高级别作为既有 ACL 投影，自定义权限不改变该基础级别。每租户最多 500 个账号、50 个自定义角色，每账号最多 8 个角色；不提供账号/角色删除。账号名 3–100 字符，以小写字母开头，允许小写字母、数字、点、下划线和横线。显示名及角色名最多 80 个字符。

自定义知识管理员在上传、版本列表、提取预览、原文件下载/归档/恢复、ACL、激活/撤回及上传幂等重放中继续检查知识库 ACL 和团队资格。创建知识库必须包含自己的基础角色；资源改为不可读后，旧请求键也不能返回文档元数据。Python 不持有身份表写权限。

## 并发和恢复

管理写取得租户授权排他锁，再锁操作者和目标账号；登录/刷新/退出及 Agent 执行取得对应共享锁。并发管理员停用串行复核，不能同时移除最后一个管理员。登录在密码校验后重新读取用户版本，刷新产生的替代会话也会被随后提交的重置撤销。普通幂等写在资源验证后锁用户，复核 auth_version 和当前会话，失效请求导致整笔事务回滚；该检查之后不再获取业务资源锁。

密码使用 bcrypt 保存；HMAC 只参与请求摘要，不进入返回正文。丢失响应后保留原 Idempotency-Key 和完全相同内容重试，不重复撤销重置后新建的会话。修改内容使用新键。409 VERSION_CONFLICT 时关闭编辑框、刷新管理数据并重新核对。停用角色保留关联，重新启用会刷新权限并撤销会话；编辑账号时应移除已停用的角色，不能新增分配停用角色。

账号更改使旧任务 family 失效，重新登录不会复活旧 run 的批准/执行凭证；已提交事务、不可变回执和审计不删除。建议先完成或取消待审批任务再调整账号，被撤销的任务不能凭新登录继续原动作。

## 升级和验收

迁移 2026110503_accounts_roles.sql 新增 Go 表及字段，回填旧账号基础关联，新租户/旧版用户 INSERT 自动关联角色；不改变既有密码。UsersModel INSERT 归一化 revision/auth_version/extra_permissions。角色必须通过管理 API 调整，不支持直接修改 users.role 或 user_roles 绕过权限投影和会话撤销。

实际结果见[公开 API 报告](../reports/m7/accounts-acceptance.json)和[实施记录](progress.md)。数据库测试覆盖跨租户/分页、权限并集、会话及已批准动作撤销、并发管理员保护、登录/刷新竞争、晚期审计失败回滚、知识资源范围及重放；浏览器覆盖新增角色/账号、丢失响应同键重试、重置密码和停用。未实施远程部署、自助注册/改密、SSO、MFA、密码邮件、角色继承或任意权限表达式。
