# M7.4 原文件归档与授权下载

本阶段为 PDF 增加可选 S3 兼容归档，TXT/Markdown 保持现有 PostgreSQL 保存。默认配置仍为 postgres，已有 PDF 无需迁移即可继续索引和下载。浏览器和 Python 只通过 Go 读取原文件，不访问桶或持有存储凭据。

## 一致性和恢复

上传事务仍先保存完整原字节、SHA256、不可变版本及索引 outbox；启用 S3 时同事务追加独立归档 outbox。归档执行器在数据库事务外以服务器生成的租户/版本/hash 键条件写入对象，读取并核对长度及 SHA256，随后在持有当前 outbox 代次/有效租约的事务中切换存储定位并清除数据库字节。外部存储失败时保留数据库原文件，不阻塞已经可用的索引和下载。

写对象后崩溃或数据库提交失败，重试校验同一不可变对象；已有不同内容禁止覆盖。旧 worker 失去代次后不能清除字节或修改定位。已归档文件读取失败/损坏返回固定错误，不返回空文件，也不猜测桶或对象路径。定位绑定存储 endpoint/region/bucket 的指纹，配置变更不静默指向另一个存储。归档重复执行不修改索引状态、激活版本或审批。

管理员可显式对历史数据库 PDF 请求归档，也可在修复存储后重新投递死信；操作有当前授权、租户/文档绑定和审计。没有自动删除对象或垃圾回收，避免与索引恢复、下载和备份竞争。撤回业务文档只撤销政策引用，不删除管理员管理的原文件。

## 授权下载

新增管理员原文件接口，接收 document/version ID 并返回有界 JSON base64、文件名和 hash；不接收 URL、bucket 或 key，不生成公开或预签名链接。外部读取前后重新验证当前会话/角色和租户绑定。下载按钮通过 Go 获取数据后生成浏览器附件，PDF 以附件保存，不执行内容或嵌入 HTML；普通操作员继续只能读取当前有效引用。

## 验收范围

本地独立 SeaweedFS 提供真实 S3 协议验收，使用固定版本/镜像 digest；单节点示例用于开发和可复跑验证，不代替生产存储规划。测试覆盖数据库兼容、归档/索引独立执行、写后响应丢失、不同内容拒绝覆盖、租约接管、授权撤销、外租户拒绝、损坏/缺失对象及下载 hash。现有 OCR、引用撤回和审批回归保持有效。服务器配置、备份与回退见[存储运维](../deploy/source-storage.md)，尚未执行远程上线。

## 运行限制

S3 每次 HTTP 请求上限 5 秒、SDK 不做隐式重试；归档最多读取、条件写入、读取三次，采用 outbox 的 30 秒租约及最多每轮 8 次投递。对象存储暂不可用不会改变数据库原件和索引状态；已归档对象缺失时下载/索引读取明确失败。完整对象正确后可恢复至数据库，递增 epoch 阻止旧任务再次归档。停止归档不删除已有定位或自动移回文件。

本阶段不提供分片上传、公开链接、跨桶在线迁移、自动对象删除或复杂版面还原；PDF 沿用 2 MiB 限制。生产环境只需外部私有 S3 配置，SeaweedFS overlay 为可选沙箱。默认 PostgreSQL 模式无需新增服务；下载接口同样可读取 TXT/Markdown。旧应用回退前必须先恢复全部 S3 文件并处理待投递任务。
