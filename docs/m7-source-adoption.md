# M7.12 未登记副本人工核验与登记

在 M7.11 版本范围巡检基础上，为已识别的旧 PDF 副本增加人工确认登记。数据库原件必须已恢复、仍保留且通过大小/SHA256 校验，候选必须属于当前可信租户/版本/hash、使用标准旧式或旧代次键、列表大小匹配且未登记。登记仅写 source_objects、审计及幂等回执，既有副本清理仍需独立预览确认。

## 契约与事务

- 新增 `FILE_STORE_ADOPTION_ENABLED=false`，与巡检、清理开关独立。新登记同时要求巡检及登记开关开启。
- 巡检每项增加 adoption_eligible/adoption_reason/adoption_token，页面增加 adoption_enabled。只有满足当前资格的候选获得加密认证选择凭证，绑定当前用户/租户/文档/版本/hash/存储/当前原件代次和对象键，15 分钟过期。token 不代表内容已验证。
- `POST /api/v1/documents/:document_id/versions/:version_id/source-adoptions` 要求 Idempotency-Key、object_ref、adoption_token、expected_source_epoch 和 confirm=true；成功返回 200（object_id/object_ref/version_id/source_epoch/verified_at）。source_epoch 是旧副本代次，expected_source_epoch 是数据库原件当前代次。
- 首次事务先复核当前权限、数据库原件、代次、凭证、登记冲突和副本上限；无已提交回执时退出事务，在事务外有界读取 S3 原文，校验大小和 SHA256。最终事务重新复核当前身份/ACL/团队、原件及凭证，并原子提交登记、审计和幂等回执。外部读取不持数据库锁，不写对象或切换原件定位。
- 重放先读取已有回执并复核当前资源权限/登记身份，不重复读 S3、登记或审计；原选择凭证到期、对象后来清理或新登记开关关闭后仍可读取原回执。已撤权者不能重放。同请求键修改参数返回 IDEMPOTENCY_CONFLICT。
- 新请求遇到 SOURCE_ADOPTION_DISABLED、SOURCE_CHANGED、SOURCE_ADOPTION_PROTECTED、SOURCE_ALREADY_REGISTERED（409）或 SOURCE_COPY_LIMIT（429）需重新核对；选择凭证过期 410 ADOPTION_SELECTION_EXPIRED，篡改/越界 400；内容不一致返回 SOURCE_INTEGRITY_FAILED，读取失败不补登记。

## 资格与限制

要求副本代次小于当前原件代次。旧式无代次键按 0 处理；恢复至数据库后当前代次递增，可与旧副本区分。当前/未来代次、非标准定位、零字节/大小异常、已登记/清理中/已清理对象不提供新登记资格。每版本最多 100 个未 retired 登记，沿用现有保护和后台清理机制。

迁移前已恢复、但当前原件代次仍为 0 时，旧式副本也按 0 处理，保持同代保护。可在备份后通过既有正常归档→恢复流程递增当前代次，再刷新巡检；存储校验失败时保留保护，不手改代次或登记。

校验是外部读取时的内容观察，存储随后可能被外部修改。登记不构成永久完整性保证；下载/清理仍执行已有完整性检查。范围仅限仍有可信版本身份的旧副本，不扫描未知版本，不自动批量认领，不恢复损坏数据或删除对象名。

## 验收与复跑

Go 全量 86 项顶层测试、含子用例 140 项与 vet 通过。新增测试覆盖成功登记/回执字节一致、凭证过期/关闭开关/移除存储配置/副本退休后重放、同键与不同键并发唯一效果、审计/回执失败回滚、跨租户/团队/读取期间撤权、读取期间代次变化、等长损坏 hash、缺失/读取失败、原件损坏、上限、游标混用和非法确认。

独立 mock/S3 [公开 API 3/3 报告](../reports/m7/source-adoption-acceptance.json)验证恢复→显式确认→核验登记→同键回执→已有副本清理，数据库原件及一次登记审计保留。未登记状态仅由新合成版本移除初始登记模拟，没有操作业务数据。另行回归原巡检公开接口 4/4。

Agent 隔离 schema 测试 49/49，Web 单测 4/4、类型检查与生产构建通过。Chrome 回归 12 项通过，新用例验证恢复保护、确认勾选、丢弃已提交响应、同键/同回执重试及清理预览入口；5 项既有用例因缺少额外夹具跳过，随后独立准备巡检夹具补跑其浏览器用例。实际结果和阶段范围见[实施记录](progress.md)。

脚本、开关和权限见[存储部署](../deploy/source-storage.md#未登记旧副本的人工登记)；逐步操作、重试及回退见[服务器手册 §22](../deploy/server.md#22-未登记副本人工核验与登记)。验收脚本会构造新合成版本的未登记状态并执行一次副本清理，只能用于临时 mock 栈，不能在业务库运行；本地验收不代表生产或任意供应商验收。
